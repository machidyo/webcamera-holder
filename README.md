# webcamera-holder

ELP USB4KHDR01 (38.17 x 38.17 mm 基板) 用の Web カメラホルダです。
[build123d](https://github.com/gumyr/build123d) で記述したパラメトリックモデルで、
モニタ上辺に載せる L 形ブラケットで使います。ねじ無しで組み立てられます。
カメラの角度は D 形ピンで固定され、既定は俯角 27° です。`FIXED_TILT_DEG` で変更できます。

## 部品

| 部品 | ファイル | 説明 |
|---|---|---|
| housing | `output/housing.stl` | 本体。前面レンズ開口、基板用ボス 4 本、縦スロットの通気穴、ヒンジ脚 (D 穴) |
| cover | `output/cover.stl` | 裏蓋。スナップ嵌合。コネクタ直上にケーブル切り欠き、基板を押さえる柱 4 本 |
| mount | `output/mount.stl` | L 形ブラケット。上面パッド + 前面アーム、アームにピボットボス (D 穴)。外側 2 面にテープ貼り付け用プレート (26 x 2 mm) |
| pin | `output/pin_3.9.stl` / `pin_4.0.stl` / `pin_4.1.stl` | D 形断面のヒンジピン。軸径違いを 3 本印刷し、きつく入るものを使う (頭の点の数で区別、4.0 が実績値) |

`output/webcamera_holder.3mf` に全部品を印刷向きで並べてあります。Bambu Studio にそのまま読み込めます。
`output/reprint_cover_pins.3mf` は裏蓋とピンだけを再印刷するためのものです。

## 対象基板

- ELP USB4KHDR01: 38.17 mm 角、厚さ 1.64 mm、取付穴ピッチ約 34 mm
- 基板裏面に縦型 4 ピン 2.0 mm ピッチのコネクタがあり、ケーブルが真後ろへ出るタイプ

寸法は `webcamera_holder.py` 先頭のパラメータにまとめてあるので、別の基板に合わせる場合はそこを変更してください。

## 印刷条件

- Bambu Lab A1 mini / PLA
- レイヤ高さ 0.2 mm、壁 2 から 3 本
- housing はそのままの向き (レンズ面がベッド)、cover は裏返した状態、mount はプレートが張り出していない側を下にして寝かせた状態で出力済み (サポート不要)
- ピンは寝かせて印刷する向きで出力済み (D の平面がベッド側)
- 脚の D 穴は平面側が印刷時の上になるので、ブリッジが短くサポート不要

## 組み立て

1. housing のボスに基板を載せ、cover をスナップで閉じる。cover の柱が基板の四隅を押さえて固定される
2. mount のボスを housing の脚の間に入れ、D 穴の平面を揃えて (平面は cover 側)、ピンの平面も同じ向きにして圧入する。
   ピンの D 形で回転が止まり、角度は `FIXED_TILT_DEG` (既定 27° 下向き) に固定される
3. mount の L をモニタの縁 (上辺または側辺) に当て、プレートの面をテープ / 両面テープで留める。
   プレートはバーの片側 (前面から見て右) に張り出しているので、モニタ左端に付けるとプレートがベゼル内側へ伸びる

## 設計メモ

- 通気穴は縦長スロット。印刷時に壁が垂直になるのでブリッジが不要
- mount のプレートはバーの片側面と面一にして反対側へ張り出す (`PLATE_SIDE` で向きを変えられる)。
  両側に張り出すと寝かせて印刷したときにバーとボスが浮いてサポートが要るため
- mount は housing 座標系の組み立て位置で作っているので、脚と mount の D 穴は同じ向きで切られる。
  `FIXED_TILT_DEG` は 0 から 35° (下向き) の範囲で本体・脚がパッドやモニタと干渉しない

## モデルの再生成

```sh
pip install -r requirements.txt
python webcamera_holder.py
```

`output/` に STL、STEP、3MF が出力されます。`ocp_vscode` が入っていると実行後にビューワへ表示します。
表示を抑止する場合は環境変数 `NO_SHOW=1` を付けてください。
